## Hi, I'm Achyuth

I spent five years building the systems that move money: Spring Boot microservices for retail, mobile, and corporate banking, with the maker-checker controls, tokenisation, and multi-factor auth that regulators expect. Now I build the AI that works on top of them, with the same standards: assistants that verify identity before they answer, and models that run on the device so the data never leaves it.

- 🏦 **Software Engineer at Cognizant**, on the same First Citizens Bank platform I joined at FIS Global in 2021
- 🤖 Building **on-device and agentic AI**: a voice agent for the Mac, an offline-first bank with an embedded LLM, Spring AI and LangChain4j services
- 📍 Bengaluru, India · open to opportunities
- 🌐 Everything below, with live demos, at **[achyuthkp27.github.io/Portfolio](https://achyuthkp27.github.io/Portfolio/)**
